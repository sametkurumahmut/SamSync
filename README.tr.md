# SamSync

[English](README.md)

Dosyaları birden çok makineye aynı göreli yolla gönderen araçlar.

![SamSync: Gönder sayfası](docs/screenshots/tr-send.png)

![SamSync: kaynakları bir hedefle karşılaştırma](docs/screenshots/tr-compare.png)

| Klasör | Ne |
| --- | --- |
| [`app/`](app/README.tr.md) | **SamSync** — Windows, macOS ve Linux masaüstü uygulaması: çoklu hedefe gönderim, Git commit/yerel değişiklik gönderimi, klasör karşılaştırma ve senkron (iki yönlü, ayna, güncelle), değişince otomatik gönderim, zamanlanmış senkron, yedekten geri alma, otomatik güncelleme. |
| [`legacy/`](legacy/README.tr.md) | Eski sürüm (1.x) — Explorer ve Notepad++ sağ tık menüsünden çalışan PowerShell aracı. |

İkisi aynı `config.json` dosyasını kullanabilir: SamSync eski aracın dosyasını okur ve kaydederken onun alanlarını korur.
